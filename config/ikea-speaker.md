# IKEA KALLSUP ESPHome Speaker

Based on this post: https://community.home-assistant.io/t/converting-new-5-ikea-kallsup-speaker-into-a-esphome-media-player/1000870

But instead of Sendspin, using a basic standalone media player setup. 

## Pinout
- pin_i2s_lrclk: GPIO07
- pin_i2s_bclk: GPIO09
- pin_i2s_dout: GPIO08
- play: GPIO04
- BP button: GPIO43
